OpenCode Go

可接入多个 Go 订阅。请求时按 5 小时 / 周 / 月剩余额度自动切到最宽裕的 Key。限额卡片也会出现在管理中心「配额管理」。

订阅池

写入配置需要 Management Key。已从管理中心打开本页时会自动带上。读不到时勾选登录页「记住密码」后重新登录，或把 Management Key 填到下面（不是上面的 Go API Key）。

访问代理

请求 OpenCode Go 模型时使用。默认 direct 直连。可改成 http://127.0.0.1:7890 或 socks5。

本机累计 Token

从本机插件记账的成功请求，含输入 / 输出 / 缓存命中。官方 /usage 只有剩余百分比，没有绝对 token 数。重启 CPA 会从磁盘接着累加。
